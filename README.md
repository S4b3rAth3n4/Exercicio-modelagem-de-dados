# Exercício Prático: Modelagem de Dados da EVG

Neste projeto apliquei conceitos de modelagem de dadso apresentados em aula, para contruir um mocelo do tipo star schema apartir de uma tabela desnormalizada contendo dadso públicos de matrículas e cursos da Escola Virtual de Governo ( EVG ).

Dentre os passos seguidos, as seguintes etapas abaixo foram concluidas:
1º a preparação e o versionamento;
2º importando da planilha para o power Bi;
3º foi a modelgem conceitual e lógica;
4ª parte foi a documentação do modelo;
5º implementação da modelagem física;
6º mesclagem e vínculo de chaves;
7º Limpeza da tabela fato;
8º verificação e ajustando todos os tipos de dados;
9º Criação dos relacionamentos do tipo 1:N ligando as chaves  das tabelas dimensão às chaves da table fato;
